# 空态布局、按钮矩阵与附件面板

Type: grilling
Status: resolved
Blocked by:

## Question

在已确认的总原则下，锁定可实现的交互细节并写进规格：

1. 空态：输入卡常驻底部时，问候语在「顶部栏到输入卡」剩余空间的垂直居中规则；键盘弹出、横屏、小屏、极短剩余高度如何表现；有消息与无消息是否复用同一输入卡实例与高度动画。
2. 占位文案状态机：无附件「发消息或按住说话」，有附件「发消息」；文本非空时不显示；面板展开时的占位与焦点行为。
3. 按钮矩阵逐状态落表：无文本无附件、有文本、无文本有附件、上传中/失败、生成中、转写中、朗读中、录音中、面板展开、忙碌与错误的组合；每个按钮的可用性、提示与点击结果。
4. `+` ↔ `×`：切换动画、面板高度、收起键盘的时序、点输入框恢复键盘、Android 返回键、横屏；面板展开时按麦克风/发送的行为。
5. 面板与草稿附件行的共存：高度预算、附件很多时的滚动区域、上传失败提示的优先级。
6. reduced motion 与无障碍标签。

## Deliverable

决议写入票内 Answer；必要时附 ASCII 布局图；由票 07 汇总到 `ui.md`。不写产品代码。

## Answer

用户逐条确认以下决议。尺寸中的「约」由票 06 的视觉原型收敛，交互与时序在此锁定。

### 1. 空态布局与输入卡常驻

- 空态与有消息状态使用**同一个输入卡实例、同一底部位置**，不重建。切换只改变消息区内容，输入框焦点、草稿附件与开关状态保持不变。
- 问候语只在空态显示，在「顶部栏底部到输入卡顶部」的剩余区域内垂直居中；不显示 logo。
- 键盘弹出时，问候语在缩小后的剩余区域内继续居中；剩余高度小于 96 时隐藏问候语，避免贴边与截断。
- 输入卡高度变化（草稿附件行出现或消失、输入行数变化）使用 `AnimatedSize` 200ms；`MediaQuery.disableAnimations` 为真时为 0。
- 首条消息发出后问候语 150ms 淡出。
- 横屏、小屏同样按上述剩余高度规则处理，不额外适配。

### 2. 占位文案与焦点

- 占位只由两个条件决定：附件为空且文本为空时「发消息或按住说话」；附件非空且文本为空时「发消息」；文本非空时不显示。
- 面板开合、输入框焦点、录音、转写、无 API Key 都不改变占位。
- 点 `+` 只让输入框失焦并收起键盘，占位不变；点输入框时面板收起、键盘弹出。
- 录音与转写期间输入框仍可编辑，占位照常。

### 3. 按钮矩阵

右侧顺序固定为 `+`、麦克风、发送/停止。有文本时麦克风隐藏，发送占其位置；无文本有附件时三者共存。面板展开时 `+` 显示为 `×`。

| 状态 | `+` / `×` | 麦克风 | 发送槽 | 开关 |
| --- | --- | --- | --- | --- |
| 无文本无附件 | `+` 可用 | 显示，可用 | 发送禁用（主色 35%） | 可用 |
| 有文本（附件就绪或为空） | `+` 可用 | 隐藏 | 发送可用 | 可用 |
| 有文本 + 附件上传中/失败 | `+` 可用 | 隐藏 | 发送禁用 | 可用 |
| 无文本有附件（上传中/失败） | `+` 可用 | 显示，可用 | 显示，禁用 | 可用 |
| 无文本有附件（全部 done） | `+` 可用 | 显示，可用 | 显示，可用 | 可用 |
| 生成中 | 禁用 | 隐藏 | 停止（实心方块） | 可用 |
| 录音中 | 禁用 | 隐藏（浮层接管） | 禁用 | 可用 |
| 转写中 | 禁用 | 隐藏 | 加载圈，点击取消转写 | 可用 |
| 朗读中 | 可用 | 显示，禁用 | 可用，发送前先停朗读 | 可用 |
| 无 API Key | 可用 | 可点，弹 `errorNoApiKey` | 可点，弹 `errorNoApiKey` | 可用 |

- 上传未完成时可以开始录音；转写结果自动发送会被上传闸门挡住，落点由票 05 决定。
- 面板展开时点麦克风：先收起面板，再开始按住说话。点发送：发送后收起面板。无文本时面板保持展开，供继续选照片。
- 面板展开且有文本时，麦克风按「有文本」规则隐藏。
- 深度思考与智能搜索开关除面板开合外所有状态保持可用，包括生成中、录音中、转写中；与 `ui.md` §5.2 现状一致。
- 附件全部 done 才允许发送；上传失败按现有卡片重试或移除处理。

### 4. `+` ↔ `×` 开合时序

- 图标：180ms 交叉淡入加 90° 旋转；减少动画时直接切换。
- 展开：点 `+` 立即让输入框失焦，面板以 `AnimatedSize` 220ms `easeOutCubic` 展开。不等键盘收起完成，避免输入卡与面板之间的空窗。
- 收起：点 `×` 时面板以 180ms 收起；点输入框时面板 180ms 收起并同时弹出键盘。
- Android 返回键：面板展开时先收面板，优先于侧栏与退出页面。
- 横屏：面板最大高度为屏高 45%，超出时内部纵向滚动。
- 消息列表：开合不主动滚动；仅当用户原本贴底时继续贴底。
- 朗读中开面板不停朗读。

### 5. 面板与草稿附件行共存

- 草稿附件行留在输入卡内、输入框上方（单行横滑，图片 64、文件卡 210）；面板挂在输入卡下方。
- 面板高度只由内容决定：照片横条约 96、三宫格约 88、加间距；不随附件数量或草稿行变化。
- 草稿行只横向滚动，永不换行；50 个附件也不改变高度。
- 上传中与失败只在草稿行卡片上表达（蒙层、红描边、重试）；面板内不加额外横幅。存在未完成附件时发送保持禁用。
- 配额 Toast 每个任务只提示一次，沿用现状。
- 屏幕高度不足时面板内部纵向滚动，草稿行与输入卡保持可见。

### 6. 减少动画与无障碍

- 减少动画：所有尺寸与透明度过渡为 0，布局瞬时变化，无旋转。
- 语义标签：`+`「添加附件」、`×`「收起附件面板」、照片格「照片，第 N 张，已选/未选」（`selected` 状态）、三宫格「拍照」「从相册选择」「选择文件」、草稿卡「移除附件」。具体 ARB 键由票 07 汇总。
- 面板展开不主动播报，读屏焦点不移动。
- 动态字体跟随系统；面板最大高度 45% 屏高并内部滚动；照片横条尺寸不随字号变化；三宫格文字最多两行。

### 布局示意

```text
┌──────────────────────────────┐
│ 顶部栏                        │
├──────────────────────────────┤
│                              │
│         问候语（仅空态）        │
│                              │
│ ┌──────────────────────────┐ │
│ │ 草稿附件行（有附件时）       │ │
│ │ 输入框                      │ │
│ │ 开关        [×] [🎤] [↑]   │ │
│ └──────────────────────────┘ │
│ 照片横条（面板展开时）          │
│ [拍照] [相册] [文件]           │
└──────────────────────────────┘
```

输入卡常驻底部；面板是输入卡下方的同一列内容，不是浮层。
