# 输入区视觉对图原型

Type: prototype
Status: open
Blocked by: 03, 05

## Question

用最低成本的可运行 widget / 截图原型，让用户对图确认以下视觉，不做产品集成：

1. 空态：问候语位置、输入卡高度与圆角、无 logo。
2. 按钮矩阵三态：仅 `+`/麦克风、`+`/发送、`+`(×)/麦克风/发送；选中色与禁用色。
3. 附件面板：设备照片横条（勾选态）、三宫格、面板高度与间距。
4. 草稿附件行：图片 64、文件卡 210、卡片内右上角白色圆形 `×`、文件扩展名色块图标；上传中/失败/重试覆盖层。
5. 录音浮层：蓝色渐变范围与色值、文案、波形形态、取消态（「松开取消」/变色）。
6. 深色与浅色两套；iPhone 与 Android 常见宽度。

## Deliverable

原型文件路径 + 截图，票内 Answer 记录用户逐项确认结果。实现另开图。
