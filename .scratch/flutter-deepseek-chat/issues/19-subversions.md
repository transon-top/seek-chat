# 子版本计划与 v1 验收标准

Type: grilling
Status: open
Blocked by: 11

## Question

把 v1 的 10 项功能切成可独立验收的子版本：

1. 优先级与依赖：哪些功能是后续功能的前置（如附件先于图片审核、Markdown 先于引用角标、数据模型先于导入导出）。
2. 子版本划分：每个版本的范围、验收标准、演示脚本。
3. v1 验收对照表：截图 10 项逐条映射到验收用例与测试步骤。
4. 风险与不确定性：外部 API 依赖、平台权限、性能门槛。
5. 发布顺序与回滚点；每版的可运行判定。

产出：`roadmap.md` + `spec.md` 的验收章节。
