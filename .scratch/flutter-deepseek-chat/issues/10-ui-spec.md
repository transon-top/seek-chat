# shadcn_ui 界面规格

Type: grilling
Status: resolved
Blocked by: 09, 18, 20, 21

## Question

把原型的结论固化为可实现的界面规格：

1. 页面与路由清单（聊天、设置、数据管理、导入导出）。
2. 组件映射：每个界面元素对应 shadcn_ui 组件（或自绘），列出所需自定义 widget。
3. 主题 token：颜色、圆角、间距、字体、代码 / 引用 / 表格样式；深浅色差异。
4. 响应式：手机竖屏 / 横屏、平板断点。
5. 交互状态机：发送、流式中、停止、错误、重试、分支切换、搜索中、上传中、录音中的可见状态与按钮态。
6. 无障碍：语义标签、对比度、动态字体、减少动画。
7. 文案：中英文案表（错误、空态、确认弹窗）。
8. 附件、语音、引用来源在消息流中的具体呈现。

产出：`ui.md` 章节 + 组件清单 + 状态表。

## Answer

界面规格见 [`ui.md`](../ui.md)，页面路由、组件清单、主题 token、状态表、
无障碍、文案与验收用例均在文内。

- **导航**：聊天页为根；会话列表改为左侧抽屉，按今天 / 昨天 / 7 天内 / 更早分组；
  抽屉顶部为 `Fleepseek` 文字标，底部为设置按钮。设置改为底部 Sheet，
  顶部三段导航：通用设置 / 账号管理 / 数据管理（二级视图）。
- **视觉基线**：采用本次会话补充的参考截图：助手正文通栏、来源胶囊
  （站点图标叠加 + `N 个网页`）、底部复制 / 重新生成 / 朗读操作条；
  输入区激活开关为蓝色底 + 蓝描边 + 蓝图标文字；发送按钮圆形主色。
- **主题**：`#4D6BFE` 种子生成浅深两套 Material 主题并映射 `ShadColorScheme`；
  原型的 shadcn 中性色板不进入生产。`ShadTextTheme` 全量覆盖为系统字体，
  避免回退 Geist。
- **布局**：聊天内容最大 760，设置最大 640；`<600` 紧凑、`>=600` 宽屏单列；
  手机横屏与平板不做双栏。抽屉宽 `min(320, 屏宽×0.82)`，设置 Sheet 高 92%。
- **超长消息**：不保留原型 8 行折叠；完整渲染 Markdown，单块超过 200000 字符
  按纯文本降级。
- **模型与操作**：v1 固定 `deepseek-flash`，抽屉不保留模型切换；分享、点赞 /
  点踩不渲染，避免死按钮。
- **无障碍**：44×44 点击区、动态字体 2.0、关键语义标签、减少动画、
  4.5:1 对比度；流式内容只在开始 / 结束播报。
- **文案**：新增键集中在 `ui.md` §7.2；语言选择增加「跟随系统」，写回
  `user.locale = system`，读取时按系统语言解析。
