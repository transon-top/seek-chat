# shadcn_ui 界面规格

Type: grilling
Status: open
Blocked by: 09, 18, 20, 21

## Question

把原型的结论固化为可实现的界面规格：

1. 页面与路由清单（聊天、设置、数据管理、导入导出）。
2. 组件映射：每个界面元素对应 shadcn_ui 组件（或自绘），列出所需自定义 widget。
3. 主题 token：颜色、圆角、间距、字体、代码 / 引用 / 表格样式；深浅色差异。
4. 响应式：手机竖屏 / 横屏、平板断点。
5. 交互状态机：发送、流式中、停止、错误、重试、分支切换、搜索中、上传中、录音中的可见状态与按钮态。
6. 无障碍：语义标签、对比度、动态字体、减少动画。
7. 文案：中英文案表（错误、空态、确认弹窗）。
8. 附件、语音、引用来源在消息流中的具体呈现。

产出：`ui.md` 章节 + 组件清单 + 状态表。
