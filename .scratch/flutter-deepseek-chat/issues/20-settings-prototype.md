# 设置、语言与数据管理界面原型

Type: prototype
Status: resolved
Blocked by: 04, 16, 17

## Question

1. 设置页结构：API Key、模型、深度思考、语言、所在地、主题、数据管理。
2. 语言与所在地选择器的交互；未设置状态。
3. 导入 / 导出入口、文件选择、覆盖确认、进度与失败。
4. 语音权限说明与入口（只做静态态）。
5. 删除全部数据、清除 Key 的确认流程。
6. 中英 × 浅深四组合的观感。

产出：`prototype/settings/` 或截图 / 录屏，链接到票内；不追求生产质量。

## Answer

原型在 [`prototype/settings/`](../../../prototype/settings/README.md)，截图在
`prototype/settings/screenshots/`，冒烟测试在 `test/prototype/settings_prototype_test.dart`。
入口：`flutter run -t prototype/settings/main.dart -d <设备>`。

### 1. 结构：单页分组

账户 / 对话 / 外观 / 语言与位置 / 语音 / 数据管理，一页扫完。不采用 chat-demo 的
「通用 / 数据」两段导航：v1 设置项少，数据管理放最底部并保留确认即可，多一层
切换反而增加寻找成本。语言与位置同区，符合票 16 / 18 的约束。

> 票 10 已按后续参考截图把生产布局改为三段导航 Sheet；本原型的字段与交互语义
> 保留，结构以 [`ui.md`](../ui.md) §1.5 为准。

### 2. 语言与所在地

- 语言：行内弹层单选（简体中文 / English），选中立即刷新整个界面并关闭弹层。
- 所在地：行内弹层；中文系统为省份 / 城市两级胶囊，其他系统为国家 / 地区列表。
  选中即写入并保留弹层，方便继续选城市；两栏都有「不指定」。未设置时行尾显示
  灰色「未设置」，不阻塞发送。
- 位置行说明只随消息发送、不申请定位权限；清除入口就是「不指定」。

### 3. 数据管理

- 导入：行内「选择文件」→ 假文件面板（正常包 / 268 MB 超大包）→ 覆盖确认
  （红色「确认导入」+ 建议先导出）→ 不可关闭进度框 → 行内结果。
- 失败：超大包在进度结束后显示红色「导入失败：文件过大」，不弹二次错误框；
  与 `history.md` 的状态行一致。
- 导出：进度框 → 行内「导出文件已保存」；原型控制可切到失败，显示红色
  「导出失败，请重试」。取消保存不报错（生产接系统面板）。
- 删除全部对话：确认框 → 进度 → 轻提示；保留设置与 API Key。

### 4. 语音（静态态）

只读行：麦克风权限「未请求」+ 说明（语音输入需要权限、朗读不需要、v1 仅前台）+
「系统设置」入口；不请求真实权限。朗读音色放在「对话」设置组，Stella / Tide
弹层单选（聊天页操作条另有朗读入口，不在此原型）。

### 5. 确认流程

- 清除 Key：红色文字行 → 确认框（说明需重新填写）→ 行尾回「未设置」。
- 删除全部对话：红色实心按钮 → 确认框（不可撤销）→ 进度 → 轻提示。
- 导入覆盖：见上，危险动作统一红色按钮，取消为描边按钮。

### 6. 四组合

四张主页面截图（中文 / 英文 × 浅色 / 深色）与 5 张交互截图在
[`prototype/settings/screenshots/`](../../../prototype/settings/screenshots/)；
中英切换与主题切换都立即生效。原型沿用票 09 的中性色板，生产主题按票 18 的种子
`#4D6BFE`，接入时以 `ShadTheme` 由同一种子生成。
