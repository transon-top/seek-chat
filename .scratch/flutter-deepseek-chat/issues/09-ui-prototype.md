Type: prototype
Status: open
Blocked by: 04, 08

## Question

做一个可运行的粗原型，回答「长什么样、怎么动」（聊天主界面，v1 全量控件可先用假数据占位）：

1. 会话列表：移动端抽屉；新建、重命名、删除入口。
2. 消息流：用户 / 助手气泡（或非气泡布局）、思考块折叠与计时、流式光标、停止按钮、编辑、重新生成、继续生成、分支切换控件。
3. 联网态：搜索进行中的进度提示、来源卡片 / 引用角标、阅读链接结果。
4. 输入区：多行输入、发送 / 停止、模型与深度思考 / 联网搜索开关、附件条、语音输入按钮、错误提示。
5. 附件：图片缩略图、文档条、上传进度、失败态。
6. 状态：空会话、首屏、加载、错误、断流、超长消息、内容拒答。

产出：`prototype/` 下的 Flutter 原型代码或截图 / 录屏，链接到票内；不追求生产质量。
