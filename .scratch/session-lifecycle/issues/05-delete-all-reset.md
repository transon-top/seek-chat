# 05: 删除全部触发与导入相同的重置

**What to build:** 目前历史归档的「删除全部」只清空数据，不触发导入式的界面重置：generation 不增、上传任务不清、不回到草稿，旧草稿附件可能残留。让删除全部与导入共用同一个重置命令，同时保留设置与 API Key。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 删除全部成功后 generation 递增并回到草稿，ChatPage 以新 key 重建
- [ ] 未发送的草稿附件、照片临时文件与上传任务被清空
- [ ] 设置与 API Key 保留
- [ ] 失败时不重置，数据与界面保持原状
- [ ] 更新历史归档规格中的删除全部流程
- [ ] 新增或扩展测试覆盖重置；现有历史归档测试通过
- [ ] `flutter analyze` 与 `flutter test` 通过
