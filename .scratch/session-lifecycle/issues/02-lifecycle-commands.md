# 02: 生命周期命令与抽屉 adapter

**What to build:** 把重命名、置顶、单删/批删与空会话丢弃收进 SessionLifecycle 的领域命令。抽屉只保留多选、搜索、菜单与确认框，调用命令而不再直接写 repository。删除顺序为：停掉该 Session 的活动回复 → 删除行 → 删除孤儿附件文件 → 更新当前选择；删除当前后打开剩余最近会话，无剩余回草稿。重命名命令自己 trim、忽略空与未变化；置顶命令接受 id 集合。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 重命名：trim、空标题、未变化均不写库；行为与现有行内编辑一致
- [ ] 置顶：单条与批量置顶/取消，分组移动正确
- [ ] 单删/批删：删除前停掉活动回复；行与孤儿附件删除；当前选择按规则回落
- [ ] 批量删除维持现状：repository 异常中断后续删除（隔离修复见票 04）
- [ ] 命令失败时选择状态不变，异常交给 UI 用现有 toast 提示
- [ ] 附件文件删除失败只记录日志，不阻塞
- [ ] 现有抽屉测试原样通过；新增命令单测覆盖 stop 顺序、回落与失败不变
- [ ] `flutter analyze` 与 `flutter test` 通过
