# 会话抽屉：搜索、置顶与多选规格

状态：定稿（2026-11-21）。术语见根目录 [`GLOSSARY.md`](../../GLOSSARY.md)；
界面细节见 [`ui.md`](../flutter-deepseek-chat/ui.md) §1.4、§5.10、§6.2。

## 1. 范围

本规格把会话抽屉从「按时间分组的列表」扩展为一个可搜索、可置顶、可批量操作的模块：

1. 去掉抽屉顶部的品牌文字标、收起按钮与「开启新对话」胶囊，改为常驻搜索入口。
2. 会话搜索：点击侧栏搜索入口，侧栏向右展开到全屏、对话层完全移出；
   搜标题与消息正文，骨架过渡，结果平铺并带命中片段与相对时间。
3. 置顶：新增「置顶」分组，长按菜单与多选批量两种入口。
4. 多选模式：行内勾选，底部置顶 / 删除操作栏。
5. 长按菜单取代行尾三点：重命名 / 置顶 / 多选 / 删除。

不在本规格：

- 搜索命中消息的定位与滚动锚点（点结果停在最新消息）。
- 关键词高亮、拼音 / 模糊匹配、FTS、排序切换。
- 抽屉内新建会话入口；新建继续由聊天页顶栏 `+` 与空态输入区承担。

## 2. 会话搜索

- 入口：侧栏顶部搜索入口是按钮，不接收输入；点击后侧栏向右展开到全屏，
  对话层继续右移直到完全移出屏幕，搜索框随宽度展开；右侧保留 16 内边距。
  输入框自动聚焦并弹出键盘。
- 返回：返回箭头让搜索层收回抽屉宽度，抽屉保持打开；系统返回在键盘打开时先收
  键盘，再走同一路径返回。搜索展开时禁止左滑收起抽屉。
- 页面结构：顶部返回按钮 + 圆角搜索框。输入非空时框内尾部显示圆形 X，
  点击清空文字并回到空白态。
- 空白态：只显示顶部栏，下方留空，不显示骨架。
- 匹配范围：`sessions.title`、用户消息的 `messages.text`，以及 assistant 回复的
  文本块。assistant 正文存在 `blocks` JSON 中，SQL 先按原文粗筛，再解析文本块校验；
  思考块、工具块与附件名不参与匹配。
- 空白查询视为空查询。
- 输入防抖 250ms；防抖等待与查询执行期间都显示 6 行搜索结果骨架。
- 结果行：左侧 44 圆形描边 + `messageCircle`；右侧第一行标题 + 相对时间，
  第二行命中片段。空标题显示「新对话」。
- 排序：按 `updatedAt` 倒序，平铺不分组，置顶不插队。
- 相对时间：今天 `HH:mm`；昨天「昨天 / Yesterday」；今年内「M月d日 / MMM d」；
  更早「yyyy年M月d日 / MMM d, yyyy」。
- 片段：去掉换行与多余空白；取命中位置前约 18 字、后约 60 字；截断侧加「…」；
  不标亮关键词。
- 点击结果：关闭搜索页与抽屉，打开该会话并停在最新消息。
- 无命中：垂直居中虚线圆放大镜 + 「暂无相关结果」。
- 关闭抽屉或退出搜索页时清空查询。
- `LIKE` 查询必须转义 `%`、`_`、`\`，避免用户输入被当作通配符。
- 查询失败不单独做错误页；按无结果处理，错误写 debug 日志。

## 3. 骨架列表

- 共用同一套静态骨块组件，无动画、无 shimmer。
- 抽屉首次加载：6 行会话行骨架，行高 44，圆角 12。
- 搜索页加载：6 行搜索结果骨架，行高 78，左侧 44 圆 + 右侧两行灰条。
- 首次加载不再显示进度条与「正在加载会话」；加载失败仍显示文案 + 重试。

## 4. 置顶

- `sessions.pinned` 布尔列，默认 `false`。
- 「置顶」组排在时间分组之前，只在存在置顶会话时显示；置顶会话从时间分组移出。
- 组内按 `updatedAt` 倒序；置顶与取消置顶不修改 `updatedAt`。
- 长按菜单按当前会话状态显示「置顶」或「取消置顶」。
- 多选批量按钮：选中会话全部已置顶时显示「取消置顶」，否则显示「置顶」。
  前者全部取消，后者全部置顶。
- 行内重命名、打开会话、收到新回复都不改变置顶状态。

## 5. 多选模式

- 入口：
  - 搜索入口下固定工具行右对齐的「多选」图标。
  - 长按会话行 → 操作卡「多选」；进入时选中该行。
- 进入后：搜索入口整行替换为「选择对话」/「已选择 N 个对话」+ 圆形 X；
  标题左内边距与分组标题对齐，整块与搜索入口等高，列表不上下跳动；
  搜索入口与选择标题 200ms 淡入淡出；会话行左侧勾选圈槽位宽度 0 → 32，
  同时淡入并放大，行文字随槽位右移，退出反向；行内长按菜单失效；
  点击行切换选中。
- 底部设置行替换为「置顶 | 删除」操作栏；0 选中时两项置灰不可点。
- 退出：X、系统返回、或批量操作完成。退出时清空选中。
- 与搜索互斥：选择模式隐藏搜索入口，搜索态隐藏多选入口；进入一个模式退出另一个。
- 当前会话可以被选中、置顶、删除；删除当前会话后的切换规则见 §5.1。

### 5.1 批量删除

- 确认弹窗标题「删除 N 个对话」，描述沿用单条删除的附件不可恢复说明。
- 确认后先对每个会话取消进行中的流，再逐个删除数据库记录并回收孤儿附件。
- 当前会话在删除集合内时，切到剩余最近会话；全部删完回到空聊天。
- 单个删除失败不阻塞其余会话；失败写 debug 日志，列表随 drift 更新。

## 6. 长按菜单

- 行尾不再显示三点菜单；长按会话行弹操作卡。
- 菜单项：`重命名` / `置顶` 或 `取消置顶` / `多选` / `删除`。
- 卡片样式、尺寸与锚定方式见 `ui.md` §1.4；点任一项关闭菜单。
- 长按触发一次轻震动（`HapticFeedback.mediumImpact`）。
- 无障碍：会话行暴露长按动作「会话操作」；菜单项各自可读。

## 7. 数据与迁移

- `Sessions` 增加 `pinned` 布尔列，默认 `false`。
- `schemaVersion` 1 → 2；`onUpgrade` 显式 `from < 2 → addColumn`，
  不启用破坏性回退。
- `Session` 与 `SessionSummary` 增加 `pinned`；`ChatRepository` 提供设置置顶的方法，
  列表查询携带置顶状态。
- 历史归档格式版本保持 3：
  - 导出：会话文件与索引都写真实 `pinned`。
  - 导入：读会话文件的 `pinned`，缺失按 `false`；索引中的 `pinned` 不作为来源。
- 回滚：schema 升到 2 后 drift 不降级；回滚到旧版需保留新库或重新导入归档。
  旧版导入新版归档时忽略 `pinned`，会话按时间分组显示。

`DateFormat.yMMMd`，今天用 `DateFormat.Hm`。

## 9. 验收

自动化：

1. `groupSessions`：置顶会话单独成组，其余仍按今天 / 昨天 / 7 天内 / 更早分组。
2. 搜索匹配：标题命中、正文命中、无命中、空查询、`%` 与 `_` 转义。
3. 搜索页：入口推入并自动聚焦；非空显示清除按钮；清除回到空白态；返回箭头与
   系统返回回到抽屉；无命中显示虚线放大镜 + 「暂无相关结果」。
4. 结果行：圆形图标、标题、相对时间、单行片段；片段首尾按截断加「…」；
   按 `updatedAt` 倒序，置顶不插队。
5. 骨架：首次加载与搜索防抖期间显示 6 行对应形状的骨架；查询完成后消失。
6. 抽屉头：不再出现品牌文字标、收起按钮、新建对话按钮。
7. 长按：菜单四项齐全；置顶会话显示「取消置顶」；点「多选」进入并选中该行。
8. 多选：标题计数、0 选中操作禁用、X / 返回 / 操作完成退出。
9. 置顶：批量置顶后进入「置顶」组；全部已置顶时按钮变「取消置顶」。
10. 批量删除：取消流、删库、当前会话切换、全删回空聊天。
11. 归档：`pinned = true/false` 导出后重新导入保持一致；缺失字段导入为 `false`。
12. 迁移：schema 1 数据库打开后新增 `pinned` 列，旧会话为 `false`。

手动：双主题 + 中英文 + 字号 0.8–2.0 下检查搜索页、骨架、长按菜单、
勾选圆圈、底部操作栏不裁切；键盘弹出时列表可用。

## 10. 风险

- 搜索展开与抽屉的返回层级：系统返回依次收键盘、收回搜索、关闭抽屉；
  PushMenu 用 `backHandler` 协调，避免一次返回同时收起搜索与抽屉。
- 1000 会话压测数据下 `LIKE` 查询的响应时间；超过 200ms 再考虑 FTS。
- 长按是主要操作入口，可发现性低；读屏与新手引导只能靠语义动作与文档补足。
- schema 升版后的回滚限制见 §7。
