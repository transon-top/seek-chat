# 06: 蓝色动态浮层视觉

**What to build:** 把按住说话的浮层做成原型确认的视觉：贴底蓝色动态区域、漂移
团块上缘、跟随按住位置的高光与 32 根电平波形；录音、取消、识别共用同一效果，
减少动画时冻结为静态帧。

**Blocked by:** 05
**Status:** ready-for-agent

- [ ] 浮层贴底覆盖输入卡与草稿行，约 60% 屏高，不盖顶部栏、不遮消息区、不加
      全屏遮罩、不响应点击。
- [ ] 蓝区由 6 枚缓慢漂移、互相重叠的径向椭圆构成动态不规则上缘（周期约 4–6s），
      顶部全透明、底部渐到实色；不引入渐变 / 动效库，用 `CustomPainter` 自绘。
- [ ] 高光锚定按下 / 移动的真实 pointer 坐标，并随电平脉动；取消态不变红，
      只把文案换成「松开取消」。
- [ ] 波形 32 根（高 28、宽 2.4、间距 1.6），电平平滑后约 30fps 插值；录音未开始
      为静止低幅骨架，识别中保持低幅波形；只重建浮层，不触发整页重建。
- [ ] 文案：录音「松手发送，上滑取消」、取消「松开取消」、识别「识别中」；
      15 / w500 白色，底部留白 44。
- [ ] `MediaQuery.disableAnimations` 为 true 时漂移、高光脉动与波形全部冻结为
      静态帧；进退场过渡归零。
- [ ] 删除旧录音状态胶囊组件；删除废弃 ARB `voiceInput`、`voiceInputRecording`、
      `voiceInputStop`、`voiceInputTranscribing`、`voiceInputCancel`，重跑
      `flutter gen-l10n`。
- [ ] 测试覆盖：三文案、波形骨架、语义播报、减少动画冻结、浮层不拦截点击。
