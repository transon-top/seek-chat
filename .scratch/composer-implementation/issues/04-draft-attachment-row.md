# 04: 草稿附件行样式

**What to build:** 草稿附件行改成截图样式：单行横滑、卡片内移除徽标、文件卡显示
扩展名配色的色块图标。上传中、失败、重试与移除语义保持不变。

**Blocked by:** 01
**Status:** ready-for-agent

- [ ] 附件行高 76，单行横滑、永不换行、间距 8；50 个附件也不改变高度。
- [ ] 图片 64×64、圆角 12；移除徽标为卡片内右上角 20 白色圆（半透明底 + `×`）。
- [ ] 文件卡 210×64；左侧 36×36 扩展名配色色块图标；文件名 12 单行省略，
      第二行「扩展名 + 大小」；移除徽标同样在卡内右上角。
- [ ] 上传中显示蒙层 + 中心 18 加载圈；可重试失败显示红描边 + 白色重试图标，
      点击重试；不可重试失败显示红描边 + 原因；失败只在草稿卡表达。
- [ ] 移除即从草稿移除；上传中取消排队 / 在途任务，迟到的成功结果丢弃。
- [ ] 测试覆盖：单行横滑、两种卡片尺寸、卡内徽标、扩展名色块、上传中 /
      可重试 / 不可重试覆盖层与移除取消。
