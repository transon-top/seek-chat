# 字体大小设置

## 决策摘要

| 项 | 决定 |
| --- | --- |
| 入口 | 通用设置新增「字体大小」分组，位于「主题」与「语言」之间；「跟随系统」开关 + 七档滑杆 |
| 默认 | 跟随系统：`ui.fontScaleFollow` 缺省为 `true`，首帧同步读取 |
| 跟随系统 | 使用系统 `textScaler`，夹到 0.8–2.0；滑杆 thumb 停在系统字号最近的档位 |
| 手动档位 | 七档 0.82 / 0.88 / 0.94 / 1.00 / 1.12 / 1.24 / 1.35；第 4 档「标准」= 1.0 |
| 联动 | 点/拖任意档位即关闭跟随；开关重新打开回到系统字号；手动档位保留 |
| 字重 | 不设 App 档位，始终跟随系统粗体（iOS、Android 12+） |
| 生效范围 | 全部文字（聊天、Markdown、输入区、设置 Sheet、弹窗、Toast）；图标、图片、间距、控件高度不缩放 |
| 应用层 | `ShadApp.builder` 覆盖 `MediaQuery.textScaler`，位于 Navigator 之上 |
| 存储 | `ui.fontScaleFollow`（bool）+ `ui.fontScaleLevel`（int 0–6）；启动同步读取，改档立即落盘 |
| 读屏 | 档位名：最小 / 小 / 较小 / 标准 / 较大 / 大 / 最大（en: Smallest / Small / Medium / Default / Large / Larger / Largest） |

## 验收

- 系统字号 0.8–2.0 全范围不裁切、不重叠、按钮可触达；超过 2.0 被夹住。
- 关闭跟随后系统改字号界面不变；重新打开跟随立即恢复。
- 七档点击与拖动全部生效；跨档触觉反馈一次；读屏值正确。
- 系统粗体开启后正文与设置文字加粗。
- 中英文案齐全；浅色 / 深色正常；首帧无字号闪烁。

## 备注

- `ShadSlider` 的轨道点击区只有轨道高度（2px），滑杆改用自绘轨道 + 44×44 手势区，保留七刻度外观。
