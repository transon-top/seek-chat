# 设置与用户元信息

状态：已实现 · 最后核对：2026-11-23
适用：SeekChat `0.5.0+1` · 数据库 `schemaVersion 2` · 归档格式 `3`

## 1. 范围与入口

系统设置 Sheet 的「通用设置」页，以及随消息请求发送的用户元信息。
包含主题、字体大小、语言、所在地、朗读音色、麦克风权限与 API Key。

入口：

- 会话抽屉底部「设置」。
- 无 Key 提示条或「无 Key 点发送」直接进入「数据管理」页并聚焦 Key 输入框。
- 设置 Sheet 顶部两个导航项：通用设置、数据管理。

## 2. 行为与状态

### 2.1 设置 Sheet

- 从底部弹出，占屏 92%，顶部圆角 24；宽屏内容最大 640 居中。
- 顶部标题「设置」与关闭按钮。
- 两个导航项在当前 Sheet 内切换，选中项为灰底胶囊。
- 关闭 Sheet 后设置立即保留；没有「保存」按钮。
- 数据管理页的导入、导出、删除全部对话见
  [历史导入导出](history-archive.md)。

### 2.2 主题

- 三档：浅色、深色、跟随系统；默认跟随系统。
- 切换立即生效并持久化；重启后保持；跟随系统时随系统主题变化。
- 浅色与深色由同一种子色 `#4D6BFE` 派生，不维护第二套色板。
- 启动时在 `runApp` 前同步读取主题偏好；首帧即为最终主题，不闪烁。
- 状态栏图标亮度随主题切换；导航栏沿用系统默认。

### 2.3 字体大小

- 「主题」与「语言」之间有「字体大小」分组。
- 默认跟随系统；使用系统字号并夹到 0.8–2.0。
- 手动七档：0.82 / 0.88 / 0.94 / 1.00 / 1.12 / 1.24 / 1.35；
  第 4 档为「标准」（1.0）。
- 点击或拖动任意档位即关闭「跟随系统」；重新打开跟随回到系统字号，
  手动档位保留。
- 跟随系统时，滑杆 thumb 停在最接近系统字号的档位。
- 生效范围为全部文字：聊天、Markdown、输入区、设置、弹窗与 Toast。
  图标、图片、间距与控件高度不随字号缩放。
- 字重不设应用档位，始终跟随系统粗体设置。
- 修改档位立即落盘；首帧读取，无字号闪烁。
- 档位名称：最小 / 小 / 较小 / 标准 / 较大 / 大 / 最大；
  英文 Smallest / Small / Medium / Default / Large / Larger / Largest。

### 2.4 语言

- 取值：跟随系统 / 简体中文 / English；默认跟随系统。
- 系统语言以 `zh` 开头为中文，其他为英文；非法存量按跟随系统处理。
- 切换立即重建界面语言，当前页面文案同步刷新；只影响之后创建的请求。
- 已生成回复、历史消息与错误快照不改写。
- 同一个语言值同时决定界面语言与 `latest_reminder` 里的「语言」字段；
  没有单独的「模型语言」设置。

### 2.5 所在地

- 可留空；未设置时元信息保留空字段与逗号，不阻止发送。
- 选择器形态跟随**系统语言**，不跟随应用语言：
  - 中文系统：省 / 市两级下拉，数据为省级行政区与下辖城市；
  - 其他系统：国家 / 地区下拉。
- 中文系统下城市名称固定中文；元信息里的国家名按应用语言显示。
- 「不指定」用于清除：省份 / 地区选择器清空整条所在地；
  城市选择器退回省一级。
- 读取时校验地区代码、省份与城市归属；非法数据整条丢弃。
- 不申请定位权限，不采集设备位置；所在地只随消息请求发送给用户配置的 API。

### 2.6 用户元信息快照

- 每个 assistant 回复保存本轮请求的系统信息快照，格式固定五项：
  `日期,星期,所在地,平台,语言`。
- 日期为设备本地时区的 `YYYY-MM-DD`；星期按应用语言生成长名称。
- 所在地：中文界面且为中国时取市 → 省 → 中国；否则取地区名称；未设置为空。
- 平台为 `iOS` 或 `Android`；语言为 `中文` 或 `English`。
- 快照在附件补齐后、请求发出前生成并写入该 assistant 行；
  续写沿用原快照。
- 重新生成生成新快照；编辑提问生成新回复并生成新快照。
- 导入历史缺少快照的轮次不插入，也不补写。

### 2.7 API Key

- 输入 Key 后由键盘完成触发校验；校验请求 `GET /models`。
- 校验成功保存到安全存储，显示「已保存」；失败在输入框下显示错误。
- 已保存时可「清除已保存的 Key」。
- Key 只存安全存储，不写数据库、不进日志、不进导出包、不进备份。
- 401 不清除 Key，只提示更新。
- 无 Key 时聊天页显示提示条；点发送直达本页并聚焦输入框。

### 2.8 朗读音色与麦克风权限

- 朗读音色：Stella（默认，女声）/ Tide（男声）；选中即写入，
  下一次朗读生效。
- 麦克风权限只读三种状态：未请求 / 已允许 / 已拒绝或受限。
- 已拒绝时显示「打开系统设置」；从系统返回后重新读取状态。
- 不提供应用内权限开关。

## 3. 边界与错误

- 主题、语言、字号非法存储值回退默认值。
- 所在地非法数据整条丢弃，不回写存储。
- Key 校验网络失败显示网络错误；401 显示「API Key 无效」。
- Key 为空白字符串视同未设置。
- 设置 Sheet 打开期间不阻塞聊天；但导入、导出与删除全部对话期间会阻止
  再次发起同类操作。
- 切换语言不重写已生成内容；模型正文不翻译。

## 4. 持久化与兼容性

| 键 | 取值 | 默认 | 说明 |
| --- | --- | --- | --- |
| `user.locale` | `system` / `zh` / `en` | `system` | 界面语言与元信息语言共用 |
| `user.location` | JSON `{region, province, city}` | 空 | 非法数据整条丢弃 |
| `ui.themeMode` | `system` / `light` / `dark` | `system` | 首帧同步读取 |
| `ui.fontScaleFollow` | bool | `true` | 是否跟随系统字号 |
| `ui.fontScaleLevel` | int `0`–`6` | `3` | 手动档位，第 4 档为 1.0 |
| `tts.voice` | `stella` / `tide` | `stella` | 开始朗读时读取一次 |
| `speech.micRequested` | bool | `false` | 区分未请求与已拒绝 |
| `chat.thinking` | bool | `false` | 深度思考开关 |
| `chat.search` | bool | `false` | 智能搜索开关 |

- API Key 存在 `flutter_secure_storage`：iOS 使用
  `first_unlock_this_device`；Android 使用默认密码套件，不启用生物识别。
- Android `allowBackup="false"`。
- 导入历史保留全部设置与 Key，不导入归档内的设置。
- 数据库 `schemaVersion 2`；归档格式 `3`。

## 5. 已知限制

- 不提供应用内隐私说明页；元信息与审核说明分散在设置文案中。
- 国家 / 地区列表当前按码点排序，不是中文拼音排序。
- 不提供定位权限或自动所在地。
- 主题种子不可配置；没有自定义配色。
- 字号手动档位固定七档，不支持任意数值。
- 不提供账号、多用户或云同步设置。
- 主题与语言切换不重写历史内容。
- 无 Key 只提示缺失，不判断 Key 是否有效；401 单独提示。
