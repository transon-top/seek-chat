# 消息渲染

状态：已实现 · 最后核对：2026-11-23
适用：SeekChat `0.5.0+1`

## 1. 范围与入口

assistant 回复正文、过程性正文、思考块与工具结果的展示。覆盖 Markdown、
代码高亮与复制、数学公式、Mermaid 图表、链接与图片地址、流式节流与降级。

入口：聊天页消息区；回复块、思考块与搜索时间线。渲染输入只来自持久化的
`messages.blocks`，不引入额外渲染状态。

## 2. 行为与状态

### 2.1 Markdown

- 支持标题、粗体、斜体、列表、引用、表格、代码块与行内代码等常见 Markdown。
- 整块正文放在可选择的文本区域内，支持选区复制。
- 表格固定列宽：按可视宽度均分，每列最少 100；单元格按纯文本渲染。
- 单条文本块超过 200000 字符时跳过 Markdown 解析，按纯文本展示；
  主要用于防御导入的超长历史。

### 2.2 代码块

- 按围栏语言高亮；无法识别的语言按纯文本代码块展示。
- 代码块提供复制按钮，复制后显示反馈。
- 代码块与行内代码内不解析引用角标。
- 高亮配色随浅色 / 深色主题切换。
- 长代码块横向滚动，不换行折行。

### 2.3 数学公式

- 只启用 `\(...\)`（行内）与 `\[...\]`（块级）两种语法；不启用 `$...$`，
  避免 `$5`、`$100` 等价格文本被误判为公式。
- 流式期间公式随 token 增长直接重排；半截公式不抛异常，按原文显示。
- 解析失败时在公式位置显示原文。
- 公式颜色跟随正文与主题，不单独配色。

### 2.4 Mermaid

- 只有 `mermaid` 围栏闭合后才渲染图表；流式半成品按普通代码展示。
- 图表固定高度 320，支持平移、缩放、复位与全屏查看。
- 解析失败降级为等宽源码文本，不中断整条回复。
- 主题按浅色 / 深色切换。
- 不引入 WebView 与远程 mermaid.js。

### 2.5 链接与图片

- 链接只打开 `http` / `https`，使用外部浏览器。
- 无协议地址补 `https://`；其他 scheme（如 `mailto:`、页内锚点）不响应。
- Markdown 图片不加载网络资源，渲染为可点击的地址链接；无协议地址同样补全。
- 不请求任意远程图片，避免隐私与加载失败问题。

### 2.6 流式节流

- 流式时按上一帧构建耗时自适应开启更新窗口，窗口限制在 50 毫秒到 2 秒之间；
  窗口内的 token 合并为一次更新。
- 流结束、切换版本或非流式文本立即显示全文。
- Markdown 按顶层段做增量缓存：追加只重建尾段，已定稿段复用。
- 思考正文使用较小字号，不渲染链接，不挂引用角标。

## 3. 边界与错误

| 情况 | 行为 |
| --- | --- |
| 数学解析失败 / 半截公式 | 显示原文，不抛异常 |
| Mermaid 流式半截 | 按普通代码展示，不渲染图表 |
| Mermaid 从未解析成功 | 等宽源码文本 |
| 未知围栏语言 | 纯文本代码块，无高亮 |
| 单块超过 200000 字符 | 纯文本展示，不解析 Markdown |
| 链接非 `http(s)` | 不响应 |
| Markdown 图片 | 不加载，显示可点击地址 |
| 流式期间选区 | 节流窗口内可能短暂打断选择，最长 2 秒 |

## 4. 持久化与兼容性

- 渲染不产生持久化状态；同一份回复块重放得到相同结果。
- 回复块保存在 `messages.blocks` JSON 中，类型包括思考、文本、
  `server_tool_use`、`web_search_tool_result`、`web_fetch_tool_result`。
- 文本块的 `citations` 随块保存；渲染时由引用登记逻辑转为角标。
- 导入历史中的思考块可能只有耗时秒数而没有起止时间；渲染按现有字段降级。

## 5. 已知限制

- 数学公式与参考实现外观不同：使用 Latin Modern Math 字体，不追求像素一致。
- 未提供单公式的 WebView / KaTeX 像素级兜底。
- Mermaid 覆盖常见图类型，不保证所有 Mermaid 语法；复杂图可能降级为源码。
- Markdown 图片一律不内联显示，只给地址链接。
- 不提供链接预览、页内查找或图片缓存。
- 超长单块按纯文本后，引用角标 token 原样保留，不再转换为角标。
