# 联网搜索与深度思考

状态：已实现 · 最后核对：2026-11-23
适用：SeekChat `0.5.0+1` · 归档格式 `3`

## 1. 范围与入口

输入区的两个独立开关、服务端搜索工具返回的时间线、正文引用角标、
「N 个网页」胶囊与来源抽屉。

入口：

- 输入区操作行左侧：「深度思考」与「智能搜索」两个描边胶囊开关。
- 回复中的思考 / 工具时间线。
- 正文中的 `[citation:N]` 角标。
- 回复底部的「N 个网页」胶囊。
- 搜索行与浏览行的「查看全部」。

## 2. 行为与状态

### 2.1 开关与快照

- 「深度思考」与「智能搜索」默认关闭，可随时切换，只影响之后创建的回复。
- 两者同时开启即深度思考搜索；没有第三个开关。
- 回复创建时快照 `thinking` 与 `search`；进行中的回复不受后续切换影响。
- 续写沿用原回复的快照。
- 请求工具声明：`deepseek_read_url` 恒声明；`deepseek_web_search` 仅当本轮
  `search` 快照为真时追加。

### 2.2 时间线

- 只有开启深度思考时，步骤区才有可折叠标题；未开启时步骤区始终可见、无标题。
- 工具状态只有 `wip`、`done`、`failed`，由持久化块纯函数推导，不落库；
  重放同一条回复得到相同视图。
- 搜索结果、打开的页面、页内查找与阅读链接按到达顺序聚合为步骤行。
- 同一普通搜索被思考块隔开时，仍合并到首次出现的位置；深度搜索只合并
  相邻的同类型搜索。
- 阅读链接只在进行中显示，结果到达后整行隐藏。
- 搜索查询词多于一条时每 2 秒轮播一条。
- 流式结束后状态停止变化；流在结果到达前结束，对应步骤记为失败。

主要文案：

| 情况 | 文案 |
| --- | --- |
| 搜索中，有查询词 | 「搜索」+ 当前查询词 |
| 搜索中，无查询词 | 「搜索中...」；图像搜索为「图像搜索中...」 |
| 搜索成功，有结果 | 「已阅读 N 个网页」；深度搜索为「搜索到 N 个网页」 |
| 搜索成功，无结果 | 「未搜索到相关内容」；深度搜索为「未搜索到合适内容」 |
| 搜索失败 | 「联网搜索暂不可用」；用户停止后为「搜索已停止」 |
| 浏览页面成功 | 「浏览 N 个页面」+ 前 5 个页面链接 |
| 浏览页面失败 | 「浏览页面失败」 |
| 查找失败 | 「查找失败」；单项失败 tooltip「未查找到相关内容」 |
| 阅读链接进行中 | 「正在阅读」+ 页面链接 |

### 2.3 引用与来源

- 正文中的 `[citation:N]` 渲染为灰色数字小标签，点击用外部浏览器打开来源 URL。
- 来源缺失或编号越界时移除该 token；代码块与行内代码内不解析角标。
- 来源按 URL 唯一编号，从 1 开始；只有三类进入来源表：
  搜索结果、深度搜索的网页抓取结果、正文引用。
- 打开的页面、页内查找结果与阅读链接抓取结果不登记来源，没有编号，
  也不进入网页抽屉。
- 同一 URL 后到的数据只补空字段，不覆盖已有标题。

### 2.4 网页胶囊与来源抽屉

- 回复流式结束、非拒答且存在网页结果时，在正文下方显示「N 个网页」胶囊；
  流式期间不显示。
- 胶囊内最多叠加 4 个站点图标，右侧显示去重后的网页数。
- 点击胶囊、点击有结果的搜索行、点击浏览行的「查看全部」，打开同一个
  全局来源抽屉。
- 抽屉从底部弹出，标题「搜索结果」，按来源编号列出全部去重网页；
  不分页，支持下拉与点击遮罩关闭。
- 抽屉只列网页结果；仅由正文引用登记的来源不进入抽屉，但角标仍可点击。

### 2.5 搜索结果与图片搜索

- 搜索结果可带标题、站点名、日期、摘要与站点图标；字段缺失时按降级规则省略。
- 站点图标只接受 `http` / `https`，加载失败回退通用链接图标。
- `image_search` / `deep_image_search` 只影响文案；`image_url` 保存但不渲染，
  v1 不做图片结果墙。

## 3. 边界与错误

- 工具失败不提供单独重试，也没有自动重试；失败状态随回复保留，
  用户只能通过「重新生成」重发整轮。
- 搜索工具结果含错误项记为 `failed`；结果为空数组记为 `done`。
- 流在结果到达前结束：`failed`；用户主动停止：搜索行显示「搜索已停止」。
- 拒答回复不渲染时间线、正文、来源胶囊与抽屉入口。
- 含任何工具块的回复不能续写，只能重新生成。
- 正文 `[citation:N]` 在流式未闭合时按原文显示，闭合后变为角标。

## 4. 持久化与兼容性

- 不新增表或列；搜索工具调用与结果以块 JSON 存在 `messages.blocks`。
- 开关持久化在 `shared_preferences`：
  - `chat.thinking`：bool，默认 `false`；
  - `chat.search`：bool，默认 `false`。
- 每轮回复快照保存在 `messages.thinking` 与 `messages.search`，续写沿用。
- 历史请求只回传 `kind == read_link` 的工具调用与成功结果，且要求非空
  `signature`；搜索结果、搜索工具调用、深度搜索抓取结果与 `citations`
  一律不回传。
- 来源与时间线是推导视图，不落库；导入历史后按块重建。

## 5. 已知限制

- 不提供工具级重试或单步重试。
- 移动端不做角标悬停预览；长按保留系统文本选择。
- 不显示图片搜索结果墙，也不加载任意图片 URL。
- 站点图标需要远程加载，隐私与失败率按现状接受。
- 深度搜索与其他搜索的区别只来自服务端 `kind`，客户端不推断。
- 搜索命中不提供「跳转到引用位置」能力。
