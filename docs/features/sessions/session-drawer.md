# 会话抽屉

状态：已实现 · 最后核对：2026-11-23
适用：SeekChat `0.5.0+1` · 数据库 `schemaVersion 2` · 归档格式 `3`

## 1. 范围与入口

聊天页左侧的会话抽屉：分组列表、会话搜索、置顶、多选批量操作、重命名与删除。
抽屉不是 `Scaffold.drawer`，使用自研的推入式侧栏；对话内容随抽屉打开缩小右移，
关闭时恢复。

入口：

- 聊天页顶部菜单按钮。
- 从屏幕左缘右滑。
- 抽屉底部的设置入口。
- 抽屉顶部搜索入口进入会话搜索页。

## 2. 行为与状态

### 2.1 抽屉与列表

- 全高、贴左侧；打开后内容层右移屏宽的 80%，侧栏可见宽度即该距离；
  侧栏内容右侧留出被内容层覆盖的条带，操作控件不落在该条带下。
- 顶部是常驻搜索入口，只作为按钮，不接收输入；点击推入全屏搜索页。
- 不提供品牌文字标、收起按钮或新建对话入口；新建对话仍由聊天页顶栏 `+`
  与空态输入区承担。
- 会话按时间分为「置顶 / 今天 / 昨天 / 7 天内 / 更早」；当前会话高亮。
- 「置顶」组只在存在置顶会话时显示；置顶会话从时间分组移出，
  组内按 `updatedAt` 倒序。
- 组标题滚动时吸顶；组内按 `updatedAt` 倒序。
- 首次加载显示 6 行会话骨架：静态灰块、无动画、行高 44、圆角 12。
- 空列表显示「还没有会话」；加载失败显示错误文案 + 重试。
- 会话标题为空时显示「新对话」。

### 2.2 会话搜索

- 点击搜索入口后，抽屉向右展开到全屏，对话层完全移出；搜索框自动聚焦。
- 返回箭头让搜索层收回抽屉宽度，抽屉保持打开。
- 系统返回：键盘打开时先收键盘；再返回收回搜索；再返回关闭抽屉。
- 关闭抽屉或退出搜索页时清空查询。
- 输入防抖 250 毫秒；防抖等待与查询执行期间显示 6 行搜索结果骨架。
- 空白查询视为空查询，只显示顶部栏，不显示骨架。
- 匹配范围：
  - 会话标题；
  - 用户消息正文；
  - assistant 回复的文本块。
  - 不匹配思考块、工具块与附件名。
- 结果按 `updatedAt` 倒序平铺，不分组；置顶不插队。
- 结果行：左侧圆形描边图标，右侧第一行标题 + 相对时间，第二行命中片段。
- 相对时间：今天 `HH:mm`；昨天「昨天 / Yesterday」；今年内「M月d日 / MMM d」；
  更早「yyyy年M月d日 / MMM d, yyyy」。
- 片段去掉换行与多余空白，取命中位置前约 18 字、后约 60 字；
  截断侧加「…」；不标亮关键词。
- 点击结果：关闭搜索页与抽屉，打开该会话并停在最新消息。
- 无命中：垂直居中虚线圆放大镜 +「暂无相关结果」。
- 查询失败按无结果处理，错误只写 debug 日志；`LIKE` 查询转义 `%`、`_`、`\`。

### 2.3 长按菜单与重命名

- 会话行不再显示三点菜单；长按弹操作卡：重命名 / 置顶或取消置顶 / 多选 / 删除。
- 长按触发一次中等触感；点任一项关闭菜单。
- 重命名：整行变为输入框；回车或失焦提交，Escape 取消；
  `trim` 后为空或未改动不写库。
- 置顶状态随会话保留；重命名、打开会话、收到新回复都不改变置顶状态。

### 2.4 多选模式

- 入口：吸顶日期标签行右侧的「多选」图标；长按菜单的「多选」（进入时选中该行）。
- 进入后搜索入口整行替换为「选择对话」/「已选择 N 个对话」与关闭按钮；
  搜索入口与选择标题 200 毫秒淡入淡出；列表不上下跳动。
- 会话行左侧出现勾选圈，选择槽位从 0 展开到 32；行内长按菜单失效；
  点击行切换选中。
- 底部设置行替换为「置顶 | 删除」操作栏；0 选中时两项置灰不可点。
- 批量置顶按钮：选中会话全部已置顶时显示「取消置顶」，否则显示「置顶」。
- 退出：关闭按钮、系统返回或批量操作完成；退出时清空选中。
- 与搜索互斥：进入一个模式自动退出另一个。

### 2.5 删除

- 单条删除：确认弹窗「永久删除对话」+ 附件不可恢复说明；确认后先停止该会话
  正在进行的生成，再删除数据库记录并回收孤儿附件。
- 批量删除：确认弹窗「删除 N 个对话」；先停止所选会话的生成，再逐个删除；
  单个失败不阻塞其余会话，失败写 debug 日志。
- 当前会话在删除集合内时，切到剩余会话中最近的一条；全部删完回到空聊天。
- 删除不删除远端 Files API 文件。

## 3. 边界与错误

- 搜索失败不单独做错误页，按无结果处理。
- 搜索不匹配附件名、思考块与工具块。
- 置顶改变分组归属，不改变会话的活动时间。
- 多选模式下长按菜单不可用；搜索与多选不能同时存在。
- 删除会话后，本地原件只在不被任何附件行引用时回收；回收失败不阻塞删除，
  下次启动继续清理。
- 系统返回的层级由抽屉统一协调，避免一次返回同时收起搜索与关闭抽屉。

## 4. 持久化与兼容性

- `sessions.pinned`：布尔列，默认 `false`；schema 2 新增。
- `schemaVersion` 1 → 2：显式 `addColumn`，不启用破坏性回退。
- 历史归档格式保持 3：
  - 导出会话文件与索引都写真实 `pinned`；
  - 导入读会话文件的 `pinned`，缺失按 `false`；
  - 旧版应用导入新归档时忽略 `pinned`，会话回时间分组。
- 删除会话在一个事务内删除会话、消息与附件关联；提交后回收本地原件。
- 数据库已升到 2 后，drift 不提供降级；回滚到旧版需保留新库或重新导入归档。

## 5. 已知限制

- 搜索不支持关键词高亮、拼音、模糊匹配、FTS 或排序切换。
- 搜索结果不定位到命中的具体消息，只打开会话并停在最新消息。
- 置顶不支持手动排序；组内始终按更新时间倒序。
- 会话删除不可撤销；确认框不提供导出或备份入口。
- 1000 个会话以上时 `LIKE` 查询可能变慢；未启用 FTS。
- 抽屉不提供新建会话入口。
- 搜索与多选互斥，不能边搜索边批量操作。
