# 输入区与附件

状态：已实现 · 最后核对：2026-11-23
适用：SeekChat `0.5.0+1` · 数据库 `schemaVersion 2`

## 1. 范围与入口

聊天页底部输入卡、空态、按钮矩阵、深度思考 / 智能搜索开关、附件面板、
设备照片横条、草稿附件行、上传状态与无 Key 提示。

入口：

- 输入卡常驻聊天页底部，空态与有消息状态共用同一实例、同一位置。
- `+` 打开附件面板，面板展开时变 `×`。
- 语音按钮按住说话（详见 [按住说话与朗读](speech.md)）。
- 发送按钮在有可发送内容时出现；生成中变为停止。

## 2. 行为与状态

### 2.1 输入卡与空态

- 输入卡圆角 28、1px 描边、无阴影；左右外边距 16。
- 输入框默认单行，最多 5 行，之后内部滚动。
- 占位文案只有两种：
  - 无附件且文本为空：「发消息或按住说话」；
  - 有附件且文本为空：「发消息」；
  - 文本非空时不显示占位。
- 空会话时，问候语「嗨! 今天想聊些什么?」在顶部栏底部到输入卡顶部的剩余区域
  垂直居中；键盘弹出时在缩小后的区域继续居中；剩余高度小于 96 时隐藏。
- 首条消息发出后，问候语在 150 毫秒内淡出。
- 输入卡贴底，键盘弹出时随键盘上移；输入法、面板、录音浮层的开合不改变
  输入卡的底部位置。

### 2.2 按钮矩阵

右侧顺序固定为 `+`、语音、发送 / 停止。

| 状态 | `+` / `×` | 语音 | 发送槽 | 深度思考 / 智能搜索 |
| --- | --- | --- | --- | --- |
| 无文本、无附件 | 可用 | 显示，可用 | 隐藏 | 可用 |
| 有文本，附件为空或全部完成 | 可用 | 隐藏 | 可用 | 可用 |
| 有文本，附件上传中 / 失败 | 可用 | 隐藏 | 禁用 | 可用 |
| 无文本、有附件，上传中 / 失败 | 可用 | 显示，可用 | 显示，禁用 | 可用 |
| 无文本、有附件，全部完成 | 可用 | 显示，可用 | 可用 | 可用 |
| 生成中 | 禁用 | 隐藏 | 停止 | 可用 |
| 录音中 | 浮层覆盖输入卡，按钮不可见、不可操作 | — | — | 同左 |
| 识别中 | 浮层覆盖输入卡，不提供取消 | — | — | 同左 |
| 朗读中 | 可用 | 显示，禁用 | 可用 | 可用 |
| 无 API Key | 可用 | 可点，提示无 Key | 可点，打开设置 | 可用 |

- 发送可用条件：有文本或有附件；所有附件上传完成；语音空闲；会话不在生成中。
- 有文本时语音隐藏，发送占用其位置；无文本且无附件时发送不渲染。
- 面板展开时 `+` 显示为 `×`；点发送后收起面板；无文本时面板保持展开。
- 开关激活为浅蓝底、浅蓝描边与蓝色图标文字；同帧切换，不做渐变。
- 开关只影响之后创建的回复，不打断当前生成；生成中与朗读中仍可用。

### 2.3 附件面板

- `+` 立即让输入框失焦、收起键盘，面板以 220 毫秒展开；`×`、点输入框、
  Android 返回键收起；点麦克风先收面板再开始按住说话。
- 面板挂在输入卡下方、与输入卡同列，不覆盖消息区。
- 内容自上而下：设备照片横条、拍照 / 相册 / 文件三宫格。
- 高度由内容决定；横屏或屏高不足时最大占屏 45%，内部纵向滚动。
- 面板展开时 `+` 显示为 `×`；生成中禁用；录音 / 识别浮层覆盖期间不可见。

### 2.4 设备照片横条

- 每次展开固定读取最近 30 张图片，按创建时间倒序，不含视频；不翻页。
- 照片格 80×80、圆角 12、间距 8；缩略图按 200×200 解码。
- 首次加载显示 6 个与照片格等高的静态灰块骨架；无动画。
- 点击选中即把照片转为 JPEG、追加到草稿附件行并开始上传；再次点击取消选中
  并从草稿移除。
- 选中态由草稿附件的来源资产派生，同一资产不能重复加入。
- 草稿已有 50 个时，未选中的照片格降为 50% 不透明度，点击提示数量上限；
  已选中的仍可取消。
- 权限四态：
  - 未决定：展开面板时请求；面板立即展开，横条先显示骨架。
  - 已允许：加载最近照片。
  - 受限（iOS limited / Android 部分访问）：只显示可访问照片，
    最左端插入「管理」格；可访问资产为 0 时只显示「管理」格。
  - 已拒绝：横条原位显示「无法访问照片」+「去设置」；三宫格仍可用。
- 已授权但图库为空显示「没有最近照片」；读取失败显示「无法读取照片」+「重试」。
- 从后台、系统设置或「管理」选择器返回时重新检查权限并重载横条；
  草稿行与勾选不受影响。
- Android 可用构建开关 `SEEK_CHAT_PHOTO_STRIP=false` 关闭照片横条及其权限申请，
  面板只剩三宫格；iOS 不受影响。

### 2.5 拍照、系统相册与文件

- 拍照：调用系统相机，质量 90、长边不超过 2560；返回后直接加入草稿并上传，
  无二次确认；取消则无变化。
- 系统相册：系统多选界面，一次最多补齐到 50 个；iOS 使用 PHPicker，
  Android 13–15 使用系统 Photo Picker。
- 文件：系统文件选择器多选，按扩展名白名单校验。
- 相机与相册的产物同样先转 JPEG；不回写照片横条勾选，也不能与横条资产去重。
- 草稿已满 50 时，「拍照」「相册」不打开系统界面，直接提示数量上限。
- 从系统选择器返回后：面板保持展开、键盘保持收起、焦点不移动、横条不刷新；
  新附件追加到草稿行；用户取消则一切不变。

### 2.6 草稿附件行与上传

- 草稿行在输入框上方、输入卡内；单行横滑、永不换行，高 76；50 个附件也不改变高度。
- 图片 64×64、圆角 12；文件卡 210×64，左侧 36×36 扩展名配色色块。
- 移除徽标在卡片内右上角，20 圆形。
- 选中即上传；单附件同一时刻只允许一个任务；并发上限 3，其余排队。
- 上传中显示蒙层与加载圈；可重试失败显示红描边与重试图标；
  不可重试失败显示红描边与原因。
- 移除附件会取消排队中或在途的上传；迟到的成功结果丢弃。
- 上传失败只在草稿卡表达，面板内不加额外横幅。

### 2.7 发送与补传

- 发送时把附件原件复制到应用支持目录，数据库存相对路径；先写文件再写数据库。
- `serverId` 为空的附件在发送前补传：
  - 本轮：并行补传，任一失败则不发起消息请求，回复显示 `upload` 错误；
  - 历史轮次：从最新往前逐张补传，失败静默跳过，本次请求不带该附件。
- 补传成功把 `serverId` 写回所有引用同一附件的消息。
- 服务端判定 `file_id` 失效时清空对应 `serverId`，重新上传并重发；
  最多重试 2 次，退避 1 秒、2 秒；已收到内容块则不重发。
- 提问与回复落库后立即清空输入框与草稿，不等回复生成结束；发送失败保留草稿并提示。
  生成中继续输入的新文本不被清空。

### 2.8 无 API Key 提示

- 没有 API Key 时，输入卡上方常驻警示底提示条：图标 + 说明文字 + 「去填写」，
  整条可点击，不可关闭；有 Key 后自动消失。
- 点提示条：打开设置 Sheet 并落在「数据管理」页，聚焦 API Key 输入框。
- 有文本或附件时点发送且无 Key：打开同一设置落点，不发送、不弹提示，
  输入内容与草稿原样保留；从设置返回后不自动发送。
- 其他入口（麦克风、`+` 附件、朗读、重新生成、续写、编辑提交、上传重试）
  行为不变，仍提示无 Key。
- Key 为空白字符串视同无 Key；Key 无效（401）不出现提示条。
- 流式回复进行中清除 Key：提示条立即出现，当前请求继续，不中断、不清空。

## 3. 边界与错误

- 扩展名白名单与 chat-demo 对齐；无扩展名不支持；`heic` / `heif` 不在白名单。
- 大小上限：`user_data` 32 MB；图片与版面解析（pdf / doc / docx / ppt / pptx）
  64 MB。
- 单次草稿最多 50 个；任一文件不合法则整批不加入。
- 图片按扩展名判定，并写入附件元数据。
- 上传失败文案：服务端繁忙、网络 / 429、解析失败、配额上限、其他 400；
  可重试项显示重试图标。
- 发送前补传失败：回复级 `upload` 错误，显示原因与「重试」。
- 原件缺失（本地路径为空或文件不存在）：只展示元数据，不进入请求，
  不提供补传入口。
- 消息内附件：图片可全屏查看；文档只展示文件名、扩展名与大小，不做应用内预览。
- 进程被系统回收时不恢复草稿、照片勾选或系统选择器状态。

## 4. 持久化与兼容性

- 草稿只在聊天页内存，不写数据库、不进历史归档；离开页面即丢弃。
- 照片横条的选择状态只存在于当前页面内存。
- `attachments` 表：文件名、大小、是否图片、MIME、相对路径、`serverId`。
- `message_attachments` 表：消息与附件的引用关系与顺序。
- 一个原件可被多条消息引用；发送、编辑、重新生成沿用同一附件。
- 删除会话时删除消息与附件关联，提交后回收不再被引用的本地原件；
  远端 Files API 文件不删除。
- 应用支持目录下的 `attachments/<id>` 存原件；数据库不存绝对路径。
- 数据库 `schemaVersion 2`；本功能未新增表或列。

## 5. 已知限制

- 草稿不跨页面、后台或进程持久化。
- 不支持拖拽、粘贴附件；只支持面板与系统选择器。
- 不支持应用内文档预览；文档需在外部应用打开。
- 不调用 Files API 删除远端文件。
- Android 关闭照片横条时只能通过三宫格选图。
- Google Play 的 `READ_MEDIA_IMAGES` 广访问权限可能被拒；被拒时使用构建开关。
- HEIC 依赖平台解码；个别机型方向异常。
- 照片横条与系统相册 / 相机无法去重。
